# Verdict Report Template

Write the saved report to `app-idea-research-<slug>.md` in the current working directory, following
this structure. Keep it factual and brutally honest — every score and claim traceable to evidence,
scores anchored to evidence not vibes, and fatal flaws stated plainly (never softened to encourage).
Delete sections that genuinely don't apply; don't pad. Lead with the verdict.

```markdown
# App Idea Research — [Idea name]

_Generated by the app-idea-research skill on [date]._

## Verdict: [BUILD / MAYBE / PASS] — [Overall X/10]

**Platform:** [iOS/Mac-only | Android-only | Multiplatform] — [sub-platforms, e.g. iPhone + Mac]
**One-line pitch:** [How a user would describe it to a friend in one sentence]
**Bottom line:** [2-3 sentences: the honest call and the single biggest reason for it.]

## Scores (1-10)

| Dimension | Score | Why |
|-----------|:-----:|-----|
| Demand | X | [evidence] |
| Pain severity | X | [evidence] |
| Monetization | X | [evidence] |
| Competition / saturation | X | [evidence] |
| Feasibility | X | [evidence] |
| Timing (why now) | X | [evidence] |
| Differentiation | X | [evidence] |
| Distribution | X | [evidence] |
| **Overall** | **X** | [gestalt — note any fatal dimension that caps it] |

## The idea

[Detailed description: the concept, the target user/persona, the core job it does, and the
specific workflow it replaces. Concrete, not aspirational.]

## Why this platform

[Justify the iOS/Mac-only vs Android-only vs Multiplatform call from where the pain, willingness to
pay, and feasibility concentrate. Name the frameworks/capabilities it depends on. If multiplatform,
recommend a lead platform to launch first and why.]

## Evidence

- **Demand / pain:** [links to real threads with engagement metrics, from ≥2 communities]
- **Competitors:** [existing apps + install/review counts + the specific gap]
- **Market / trends:** [trend data, category growth, "why now" trigger — sourced]
- **Demographics:** [persona, rough addressable size, platform spend skew — sourced]
- **Monetization:** [category paid-app evidence + realistic revenue read]
- **Frameworks:** [latest Apple/Android capabilities that make it possible/redundant/threatened]

## Examples

[Make it concrete:]
- **Comparable apps:** [what exists, what they get right/wrong]
- **Core features (MVP):** [the 2-3 features that carry the value]
- **User stories:** ["As a [persona], I [do X] so that [outcome]" — 2-3]

## Risks & what would kill it

- [Fatal or serious risk 1 — e.g. platform will absorb it, incumbent gives it away free, margins too thin]
- [Risk 2]
- [What single piece of evidence, if found, flips the verdict]

## MVP scope (if BUILD or MAYBE)

[Smallest shippable version that tests the core bet, and the honest effort estimate. Skip if PASS.]

## Confidence

[High / Medium / Low] — [what evidence is thin and what would raise confidence.]
```
