# Multilingual / i18n

Fetch current multilingual config keys via `find-docs`
(`docs /gohugoio/hugo "multilingual mode and translation"`).

## Configuration

- Define languages under `[languages]` in config, each with its own `title`, `weight`,
  `languageCode`, `contentDir`, and `[languages.<lang>.params]`.
- Two content strategies: **translation by filename** (`post.en.md`, `post.de.md` in one tree) or
  **translation by content directory** (separate `content/en`, `content/de` via `contentDir`).
  Pick one and keep it consistent.

## Translating strings

- UI strings live in `i18n/<lang>.toml` and are used with `{{ i18n "key" }}`; provide every key in
  every language, with a default-language fallback.
- Link between translations with `.Translations` / `.AllTranslations` to build a language switcher;
  set `hreflang` from `.Translations` for SEO.

## Guidance

- Set `defaultContentLanguage` and decide `defaultContentLanguageInSubdir` deliberately (affects
  URLs). Fetch the exact behavior before relying on it.
- Keep dates/numbers locale-aware; Hugo formats respect the language's settings.
